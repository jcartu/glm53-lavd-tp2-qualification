options:
  -h, --help            show this help message and exit
  --host HOST           Server host or full URL (default: localhost). Accepts
                        a full URL with scheme (e.g. https://ai.example.com)
                        for HTTPS endpoints.
  --port PORT           Server port (default: 5000, or appended to URL when
                        --host is a URL)
  --api-key API_KEY     API key for authenticated endpoints (sent as
                        Authorization: Bearer header)
  --prompt PROMPT       Prompt text for --completion-stats mode. Mutually
                        exclusive with --prompt-file.
  --prompt-file PROMPT_FILE
                        Prompt file for --completion-stats mode. '-' reads
                        stdin. If omitted, --completion-stats uses the built-
                        in estonia test profile.
  --test-profile, --profile {estonia,estonia-legacy,estonia-long,estonia-v1,estonia-v2,gpqa,gpqa-diamond,gpqa_diamond,gsm-8k,gsm8k,hotel,hotel-lights,lavd,lavd-test,ledger-lavd,lights,mmlu-pro,mmlu-pro-1000,mmlupro}
                        Run a built-in long-answer test profile. Available:
                        estonia, estonia-long, estonia-v1, gpqa-diamond,
                        gsm8k, hotel-lights, lavd-test, mmlu-pro. hotel-lights
                        is a compact reasoning test with expected answer 48.
                        lavd-test is a context consistency test: arithmetic
                        any model can do, but the model must find human errors
                        in long structured data and understand how to repair
                        them before computing ticket count and hours. gsm8k,
                        mmlu-pro, and gpqa-diamond are pinned multi-item
                        accuracy benchmarks (1319 math problems / 1000
                        stratified multiple-choice questions / 198 graduate-
                        level science questions, one item per request,
                        temperature 0) intended for quantization A/B
                        comparisons via --compare-baseline. Setting this
                        implies --completion-stats.
  --completion-stats    Run the adaptive completion-token statistics benchmark
                        instead of the decode matrix. This mode warms prefix
                        cache once, probes parallel decode concurrency,
                        selects the fastest level, then collects enough
                        completed answers to summarize how many decode tokens
                        the model needs for the task.
  --completion-stats-min-results COMPLETION_STATS_MIN_RESULTS
                        Minimum completed runs to collect at the selected
                        concurrency in adaptive --completion-stats mode.
                        (default: 30)
  --completion-stats-runs, --profile-runs COMPLETION_STATS_RUNS
                        Total measured profile requests. With --profile-
                        concurrency this is an exact request count. 0 uses
                        --completion-stats-min-results. (default: 0)
  --completion-stats-concurrency, --profile-concurrency COMPLETION_STATS_CONCURRENCY
                        Fixed concurrency for built-in profile / completion-
                        stats runs. 0 keeps adaptive probing via --completion-
                        stats-concurrency-levels. (default: 0)
  --completion-stats-concurrency-levels COMPLETION_STATS_CONCURRENCY_LEVELS
                        Comma-separated concurrency levels to probe in
                        --completion-stats mode. (default: 1,2,4,8,16,30)
  --completion-stats-probe-waves COMPLETION_STATS_PROBE_WAVES
                        Probe requests per concurrency level are concurrency ×
                        waves, except C=1 uses waves. (default: 1)
  --completion-stats-min-improvement COMPLETION_STATS_MIN_IMPROVEMENT
                        Required aggregate tok/s improvement to keep
                        increasing concurrency. (default: 0.03 = 3%)
  --completion-stats-patience COMPLETION_STATS_PATIENCE
                        Number of non-improving probed levels before adaptive
                        search stops. (default: 1)
  --completion-stats-auto-stop, --no-completion-stats-auto-stop
                        Stop probing after --completion-stats-patience non-
                        improving levels. Use --no-completion-stats-auto-stop
                        to probe all levels.
  --completion-stats-correct-regex COMPLETION_STATS_CORRECT_REGEX
                        Regex used to score correctness in --completion-stats
                        mode. Empty string disables scoring. (default:
                        \\bestonia\\b)
  --completion-stats-score-source {final_answer,content,output}
                        Text region used for correctness scoring. final_answer
                        = last non-empty answer line. (default: final_answer)
  --completion-stats-save-text
                        Keep longer output excerpts in JSON for --completion-
                        stats. Default keeps only final answer/excerpt
                        metadata.
  --completion-stats-no-prefill-scout
                        Do not send the initial max_tokens=1 prefix-cache
                        scout request in --completion-stats mode.
  --completion-stats-temperature COMPLETION_STATS_TEMPERATURE
                        Optional temperature override for --completion-stats
                        requests. Default leaves server/model default
                        unchanged.
  --completion-stats-top-p COMPLETION_STATS_TOP_P
                        Optional top_p override for --completion-stats
                        requests. Default leaves server/model default
                        unchanged.
  --completion-stats-seed COMPLETION_STATS_SEED
                        Base sampling seed for --completion-stats/profile
                        requests. Run i is sent with seed = base + i, so
                        resamples differ from each other but are identical
                        across engines/quants. Default sends no seed (engine
                        picks).
  --completion-stats-stall-timeout COMPLETION_STATS_STALL_TIMEOUT
                        Stall watchdog for --completion-stats/profile streams:
                        if no token arrives for this many seconds the request
                        is closed and scored STALL. 0 disables. (default: 600)
  --completion-stats-request-timeout COMPLETION_STATS_REQUEST_TIMEOUT
                        Wall-clock watchdog per --completion-stats/profile
                        request in seconds: a stream still running after this
                        long is closed and scored TIMEOUT. Catches models that
                        loop without ever stalling when max_tokens is omitted.
                        0 disables. (default: 0)
  --reasoning-effort {none,minimal,low,medium,high,xhigh,max}
                        Optional OpenAI reasoning_effort for completion-
                        stats/test-profile requests. Default leaves the model
                        template default unchanged.
  --compare-baseline COMPARE_BASELINE
                        Path to a previous completion-stats results JSON from
                        the same dataset profile (gsm8k, mmlu-pro). After this
                        run finishes, a paired per-item comparison is printed
                        and embedded in the output JSON: accuracy delta,

                        category deltas, and completion-token inflation.
  --compare-candidate COMPARE_CANDIDATE
                        Standalone comparison mode: compare --compare-baseline
                        against this results JSON and exit without contacting
                        any server. Requires --compare-baseline.
  --concurrency CONCURRENCY
                        Comma-separated concurrency levels (default:

  --contexts CONTEXTS   Comma-separated context lengths in tokens, supports k

  --duration DURATION   Duration per test cell in seconds (default: 30)

                        Burst / E2E-only decode mode: send exactly this many

  --burst-request-count BURST_REQUEST_COUNT

  --burst-warmup-request-count BURST_WARMUP_REQUEST_COUNT

  --burst-requests-per-concurrency BURST_REQUESTS_PER_CONCURRENCY

  --max-tokens MAX_TOKENS
